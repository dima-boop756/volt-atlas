## Система

- **Цвет.** Минеральное поле `#F1F2ED`, графит `#111714`, зелёный `#28352C`, лайм `#C5F56B`, приглушённый `#8D9990`. Для второстепенного текста на светлом фоне используется более тёмный оттенок с читаемым контрастом. Графики получают дополнительные природные оттенки зелёного.
- **Шрифт.** Manrope 700–800 для заголовков, логотипа и цифр. IBM Plex Sans 400–600 для текста, навигации, полей и подписей. Кириллические и латинские поднаборы хранятся локально.
- **Сетка.** Максимальная ширина 1600 px, поля на десктопе 48–64 px, мобильные поля 16 px. Основные интервалы 8, 12, 16, 24, 32 и 48 px. На широком экране панорама занимает около 520 px по высоте. Основной заголовок 76–90 px на десктопе и 39–44 px на мобильном.
- **Компоненты.** Тонкие границы, радиус 5–8 px, линия активной навигации, один лаймовый призыв к действию. Список разделён горизонтальными линиями. У деталей станции и форм фон контрастирует с картой. Иконки Lucide, преимущественно 16–20 px.
- **Движение.** Анимация служит открытию деталей и диалогов, обратной связи и перемещению по карте. При системном ограничении движения переходы сокращены.
- **Фотография.** Отдельные кадры для десктопа и мобильного. Лёгкое затемнение на стороне текста обеспечивает читаемость и сохраняет свет на автомобиле. Изображения сгенерированы, места съёмки и модель автомобиля условны.
- **Копирайтинг.** Общая навигация «Обзор», «Станции», «Аналитика». Главная «Зарядная сеть Алматы», «Найти зарядную станцию», «На карте города». Каталог «Станции», «Название или адрес», «Район», «Мощность», «Разъём», «Статус», «Карта», «Таблица», «Режим демо». Аналитика «Аналитика сети», «Станции по районам», «Типы разъёмов», «Мощность станций», «Статусы станций». Пункты меню и значения внутри изображений-концептов иллюстративны. Интерфейс использует объём и метрики из задания и базы данных.
